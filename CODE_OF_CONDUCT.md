# Code of Conduct

## Our standard

This is a technical project about an unusual idea. Disagreement is the point; contempt is
not.

Expected behaviour:

- Critique the specification, not the person who wrote it.
- Bring counterexamples. "This cannot work" is only useful with the `.myc` file that proves it.
- Assume good faith and a shared interest in getting the semantics right.
- Accept that a design decision may be made for reasons you have not read yet. The rationale
  is in `docs/`, and if it is missing, that is a bug worth reporting.

Unacceptable behaviour:

- Harassment, insults, or personal attacks of any kind.
- Discriminatory language or imagery.
- Publishing someone's private information without permission.
- Sustained disruption of discussions.

## Scope

This applies to issues, pull requests, discussions, and any other project space.

## Enforcement

Report concerns to the maintainer via GitHub (`@urbanyl`). Reports are handled privately.
Consequences range from a private warning to a permanent ban, at the maintainer's discretion,
proportional to the behaviour.

## Attribution

This code of conduct is adapted in spirit from the Contributor Covenant, reduced to what this
project actually needs.
